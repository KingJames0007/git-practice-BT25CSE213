## Assignment Description
This repository contains the practical exercises completed for the IT Workshop - I (CSP 201) Lab on Version Control Using Git. It demonstrates foundational Git workflows, including branching, merging, conflict resolution, ignoring files, and collaborating via remote repositories.

## Completed Exercises
- **Exercise 1 & 2:** Repository initialization and initial commits.
- **Exercise 3:** Bash script creation and modification (`greet.sh`).
- **Exercise 4 & 5:** Staging specific files and inspecting differences.
- **Exercise 6:** Ignoring generated files with `.gitignore`.
- **Exercise 7 & 8:** Feature branching, merging, and branch deletion.
- **Exercise 9:** Simulating and resolving a merge conflict.
- **Exercise 10 - 12:** Recovery techniques (unstage, revert, stash).
- **Exercise 13 - 15:** Remote repository collaboration (push, fetch, pull).

## Instructions to Run
To execute the bash scripts, run the following commands from the root directory of the repository:

**Exercise 01 (Greeting Script):**
```bash
bash exercise-01/greet.sh "Kushal"
```

**Exercise 02 (Menu Script):**
```bash
bash exercise-02/menu.sh
```
